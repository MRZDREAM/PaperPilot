# PaperPilot

科研论文 RAG 阅读与任务工具应用，逐步实现论文检索问答、来源引用和阅读任务管理。

## 当前进度

仓库处于初始化阶段，目前只包含项目说明、Git 忽略规则和换行规则，尚未创建可运行的 Spring Boot 应用。

## 初始技术计划

- Java 21、Spring Boot 3.5.16、Spring AI 1.1.8。
- PostgreSQL + pgvector。
- Maven Wrapper、PDF 解析、SSE。
- 先使用一个模型提供方，后续按需加入混合检索、查询改写和工具调用。

## 实现顺序

1. 验证兼容依赖，运行最小 Chat 接口。
2. 上传并解析 PDF，保存论文、版本和页码信息。
3. 完成分块、Embedding、向量入库与检索。
4. 构建最小 RAG，使用本轮召回证据生成来源引用。
5. 加入 SSE、会话记忆、关键词检索与 RRF。
6. 实现查询改写和阅读任务工具，完成真实评测及失败实验。

每个阶段验收后再进入下一阶段。检索效果和功能完成情况随实际验证结果更新。
